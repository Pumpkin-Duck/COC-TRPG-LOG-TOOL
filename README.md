- 有使用AI輔助，自己練習網頁操作的東西，介意勿用。

# CoC TRPG 團錄整理工具

這是一個用於整理 CoC TRPG 團錄的網頁工具。  
可匯入從 CCFOLIA 下載的 Log HTML 檔案，並將原始團錄轉換成較適合閱讀、編輯、輸出與保存的格式。

工具支援角色顏色調整、頻道顯示控制、區塊式排版、文字編輯、目錄跳轉、區塊移動、HTML 下載與 PDF 輸出等功能。

---

## 主要功能

### 1. 匯入 CCFOLIA Log HTML

使用者可以上傳從 CCFOLIA 下載的 `.html` 團錄檔案。

匯入後，工具會自動解析團錄內容，取得以下資訊：

- 頻道名稱，例如 `[main]`、`[info]`、`[other]`
- 發言角色名稱
- 發言文字內容
- 原始文字顏色
- 頻道分類資料

匯入完成後，工具會將團錄轉換成內部資料格式，方便後續編輯、排序、顏色調整與輸出。

---

### 2. 劇本基本資訊設定

工具提供團錄封面與基本資訊欄位，可用來製作完整的團錄頁首。

可設定內容包含：

- 劇本名
- 簡介圖片
- 簡介內容
- KP 名稱
- KP 顏色
- HO 編號
- PL 名稱
- HO / PL 顯示顏色

這些資訊會顯示在輸出的團錄預覽上方。

---

### 3. 簡介圖片上傳與貼上

工具支援兩種加入簡介圖片的方式：

- 點擊圖片區塊後選擇本機圖片
- 直接使用剪貼簿貼上圖片

圖片會顯示在簡介區塊中，並在輸出團錄預覽時顯示於頁首。

---

### 4. HO 與 PL 資訊管理

使用者可以新增多組 HO 與 PL 資訊。

每一組 HO 資訊包含：

- HO 名稱，例如 `HO1`
- PL 名稱
- 顯示顏色

功能包含：

- 新增 HO 欄位
- 修改 HO 名稱
- 修改 PL 名稱
- 修改顏色
- 刪除 HO 欄位

這些資料會顯示在團錄頁首的資訊區。

---

### 5. 明亮／暗色模式切換

工具支援明亮模式與暗色模式。

切換模式時會同步調整：

- 頁面背景色
- 容器背景色
- 主要文字色
- KP 預設文字色
- 情報區塊背景色
- 雜談區塊背景色
- 自訂頻道背景色

可讓使用者依照閱讀環境選擇適合的視覺模式。

---

### 6. 團錄預覽輸出

按下「輸出團錄預覽」後，工具會根據目前設定產生完整團錄預覽。

預覽內容包含：

- 劇本標題
- 簡介圖片
- 簡介文字
- KP / HO / PL 資訊
- 團錄本文
- 頻道樣式
- 角色顏色
- 自訂格式文字
- 目錄項目

---

### 7. 閱覽模式與編輯模式

工具分為兩種操作模式：

#### 閱覽模式

適合單純閱讀與輸出團錄。

在閱覽模式下：

- 不顯示編輯工具
- 不可修改文字內容
- 不可移動團錄區塊
- 適合確認最終排版

#### 編輯模式

適合整理、修改與調整團錄內容。

在編輯模式下：

- 可點擊團錄區塊進行文字編輯
- 可刪除指定訊息
- 可新增空白訊息
- 可置中文字
- 可移動訊息區塊
- 可設定目錄項目
- 可拆分或融合相鄰區塊

---

### 8. 團錄文字直接編輯

在編輯模式中，點擊任一團錄區塊即可進入文字編輯狀態。

可直接修改該段文字內容，修改後會同步更新內部資料。

編輯時支援保留換行，並會自動處理過多空白行，避免輸出時出現不必要的空行。

---

### 9. 編輯快捷鍵

文字編輯時支援以下快捷鍵：

| 快捷鍵 | 功能 |
|---|---|
| Ctrl + B | 粗體 |
| Ctrl + I | 斜體 |
| Ctrl + U | 底線 |
| Ctrl + Shift + X | 刪除線 |
| Ctrl + Enter | 提交目前編輯內容 |

快捷鍵會自動在選取文字前後加入對應的標記符號。

---

### 10. 自訂 Markdown 樣式

工具支援簡易 Markdown 標記，可在團錄文字中使用。

支援格式如下：

| 語法 | 效果 |
|---|---|
| `**文字**` | 粗體 |
| `//文字//` | 斜體 |
| `__文字__` | 底線 |
| `~~文字~~` | 刪除線 |
| `^文字^` | 上標 |
| `~文字~` | 下標 |
| `> 引用文字` | 引用區塊 |
| `#-文字-#` | 小字／淡化文字 |
| `#H1-文字-H1#` | 標題一 |
| `#H2-文字-H2#` | 標題二 |

引用文字會顯示成縮排樣式，並在左側出現灰色引用線。

---

### 11. 顯示／隱藏對話名字

工具提供「顯示對話名字」選項。

啟用時，角色發言前會顯示角色名稱。  
關閉時，主要對話中的角色名稱會隱藏，使團錄更接近小說式閱讀格式。

部分頻道，例如雜談頻道，仍可依照樣式需求顯示名稱。

---

### 12. 文字顏色統一

工具提供「文字顏色統一」功能。

按下後，所有角色文字顏色會統一成目前主文字色。

適合用於：

- 想讓團錄風格更一致
- 原始 CCFOLIA 顏色過於混亂
- 希望輸出 PDF 時保持閱讀舒適

---

### 13. 頻道顯示控制

工具會自動讀取團錄中的頻道，並在進階設定中列出。

使用者可以針對每個頻道設定：

- 是否顯示該頻道
- 頻道顯示名稱
- 頻道背景色
- 頻道邊框色

例如：

- `[info]` 可顯示為「情報」
- `[other]` 可顯示為「雜談」
- 自訂頻道可自行命名

使用者也可以取消勾選特定頻道，使該頻道不顯示於團錄預覽中。

---

### 14. 角色顏色調整

工具會根據匯入的團錄，自動建立角色顏色清單。

使用者可以在進階設定中修改每位角色的顯示顏色。

可調整項目包含：

- KP / 空白名稱文字色
- 各角色名稱與發言文字色
- 從原始 CCFOLIA 讀取到的角色顏色

顏色可使用色彩選擇器調整，也可直接輸入色碼。

---

### 15. 頻道區塊樣式

不同頻道會套用不同顯示樣式。

#### main 頻道

主要對話內容會以一般文字段落顯示。

#### info 頻道

情報內容會顯示為區塊樣式，具有：

- 背景色
- 左側色條
- 頻道標籤
- 較明顯的段落區隔

#### other 頻道

雜談內容會以類似對話泡泡的形式顯示，並靠右排列。

#### 自訂頻道

自訂頻道會以區塊樣式顯示，並可設定標籤名稱、背景色與邊框色。

---

### 16. 結局文字偵測

工具會自動偵測部分結局文字。

若 `[main]` 頻道中的文字符合以下條件，會被視為結局文字：

- 發言者為 KP、system 或空白名稱
- 文字中包含 `結局`、`ENDING`、`END`、`FIN`、`通關` 等關鍵字
- 文字沒有明顯對話標點

符合條件時，該段會以置中、加粗、較醒目的樣式顯示。

---

### 17. 區塊自動融合

相鄰的情報區塊或自訂頻道區塊，若屬於相同頻道且背景色相同，工具會自動將它們視覺上融合。

融合後會：

- 隱藏後續區塊重複的頻道標籤
- 去除中間多餘的圓角
- 減少區塊間距
- 讓連續情報看起來像同一組內容

`[main]` 與 `[other]` 頻道不會參與自動融合。

---

### 18. 區塊拆分與重新融合

在移動模式中，若游標靠近可融合區塊的邊界，工具會顯示拆分／融合提示。

使用者可以點擊：

- 「點此處拆開」
- 「點此處融合」

用來控制相鄰區塊是否保持融合狀態。

這適合用於整理情報段落，讓某些內容視覺上分開，或重新合併成同一組。

---

### 19. 區塊選取狀態

在編輯模式中，點擊團錄項目後，該項目會被標記為目前選取的區塊。

選取後會顯示左側編輯工具列。

目前選取的區塊會有外框提示，方便使用者辨識正在操作哪一段內容。

---

### 20. 區塊工具列

在編輯模式中，選取區塊後會顯示工具列。

工具列包含：

| 按鈕 | 功能 |
|---|---|
| 置中 | 切換該段文字置中／靠左 |
| 移動 | 進入區塊移動模式 |
| 刪除 | 刪除該段訊息 |
| 新增 | 在下方新增一段空白訊息 |
| 目錄 | 設定該段是否加入目錄 |

---

### 21. 新增團錄項目

使用者可以在指定訊息下方新增一段空白團錄項目。

新增的項目會繼承原本區塊的：

- 頻道
- 角色名稱

並預設為獨立區塊，不會自動和上一段融合。

新增後會自動進入編輯狀態。

---

### 22. 刪除團錄項目

使用者可以刪除指定的團錄項目。

刪除前會跳出確認視窗，避免誤刪。

刪除後工具會自動更新：

- 目前選取狀態
- 移動狀態
- 團錄畫面
- 本地儲存資料

---

### 23. 區塊移動功能

工具支援在編輯模式中移動團錄項目。

使用者可以選取區塊後按下移動按鈕，進入移動模式。

移動模式中：

- 被移動的區塊會顯示「移動中」
- 若該區塊屬於融合區塊，會整組一起移動
- 滑鼠移動到其他區塊上方或下方時，會顯示插入線
- 點擊插入位置後，即可將區塊移動到該處

按下 `Esc` 可以取消移動模式。

---

### 24. 浮動插入線

移動區塊時，工具會根據滑鼠位置顯示「插入到此處」的浮動插入線。

插入線會顯示在：

- 目標區塊上方
- 目標區塊下方

此功能可幫助使用者明確知道區塊移動後會被放到哪個位置。

---

### 25. 移動時保持視窗位置

當區塊被移動、拆分或重繪時，工具會嘗試保留目前閱讀位置。

這可以避免畫面因重新渲染而大幅跳動，讓編輯長篇團錄時更穩定。

---

### 26. 目錄功能

工具支援自訂目錄。

在編輯模式中，使用者可以對任一團錄項目設定：

- 是否加入目錄
- 目錄顯示名稱

若未自行輸入目錄名稱，工具會自動取該段文字前幾個字作為預設標題。

---

### 27. 左側滑出式目錄面板

畫面左側有目錄面板。

目錄面板平時會收合在左側，滑鼠移到面板上時會展開。

目錄項目會根據使用者加入目錄的團錄區塊自動產生。

點擊目錄項目後，畫面會平滑捲動到對應的團錄位置。

---

### 28. 本地自動儲存

工具會將目前資料儲存在瀏覽器的 `localStorage` 中。

自動儲存內容包含：

- 劇本名
- 簡介文字
- KP 名稱
- HO / PL 資訊
- 顏色設定
- 主題模式
- 顯示名稱設定
- 簡介圖片
- 頻道設定
- 角色顏色
- 團錄資料
- 是否已顯示輸出預覽

重新整理頁面後，工具會嘗試載入上次儲存的資料。

---

### 29. 下載 HTML

工具支援將整理後的團錄下載為 HTML 檔案。

下載內容包含：

- 團錄內容
- 目前樣式
- 目前主題模式
- 圖片與文字
- 顏色設定
- 排版設定

下載後的 HTML 會隱藏編輯用按鈕，適合用於保存或分享。

---

### 30. 儲存為 PDF

工具提供「儲存為 PDF」按鈕。

此功能會呼叫瀏覽器列印功能，使用者可在列印視窗中選擇「另存為 PDF」。

列印模式會自動調整版面：

- 隱藏工具列
- 隱藏模式切換按鈕
- 隱藏編輯按鈕
- 隱藏浮動插入線
- 移除不必要的外框
- 調整背景與文字顏色
- 優化區塊在 PDF 中的顯示效果

---

### 31. 響應式版面

工具針對不同螢幕寬度提供響應式排版。

支援：

- 桌面寬版
- 中等寬度螢幕
- 手機或小螢幕

在小螢幕上會自動調整：

- 頁面左右留白
- 容器內距
- 表單欄位排列
- 按鈕寬度
- 工具列位置
- 對話泡泡寬度
- 區塊內距

---



### 資料儲存位置

本工具的資料儲存在使用者本機瀏覽器中，不會上傳到伺服器。

若清除瀏覽器資料，先前儲存的團錄內容也可能被刪除。

---

### PDF 輸出限制

PDF 由瀏覽器列印功能產生，因此實際效果可能會依瀏覽器、紙張大小與列印設定而不同。

若區塊內容過長，可能仍會受到瀏覽器分頁規則影響。

---

### CCFOLIA HTML 格式限制

本工具目前主要針對 CCFOLIA 匯出的 Log HTML 結構進行解析。

若來源 HTML 結構與預期不同，可能會導致部分內容無法正確讀取。
