# CoC TRPG 團錄整理工具

這是一個用來整理 CoC TRPG 團錄的單頁網頁工具。  
可以匯入 CCFOLIA 或 Discord 匯出的 Log，整理成較適合閱讀、分享與保存的格式，並可輸出成 HTML 或 PDF。

## 主要功能

### 匯入團錄

支援以下匯入方式：

- 上傳 CCFOLIA 的 Log HTML 檔案
- 上傳 Discord 匯出的 Log HTML 檔案
- 上傳 Discord 匯出的資料夾

匯入後會自動解析角色名稱、頻道、訊息內容與部分顏色資訊。  
若目前已有團錄內容，重新匯入前會提示是否覆蓋。

> 注意：請不要混合上傳 CCFOLIA 與 Discord HTML，建議分開匯入。

## 基本資料設定

在輸出前，可以先填寫或調整以下資訊：

- **劇本名**：顯示在團錄標題位置
- **簡介圖片**：可點擊選擇圖片，也可以直接貼上圖片
- **簡介內容**：顯示在團錄開頭
- **KP 資訊**：可填寫 KP 名稱與代表顏色
- **HO 與 PL 資訊**：可新增、刪除與調整 HO／PL 名稱與顏色

這些內容會出現在輸出的團錄前段，適合放劇本介紹、KP、玩家與角色資訊。

## 團錄預覽與輸出

按下 **「輸出團錄預覽」** 後，會產生整理後的團錄畫面。

輸出後可使用：

- **閱覽模式**：單純閱讀整理後的團錄
- **編輯模式**：對團錄內容進行調整
- **下載 HTML**：下載整理後的 HTML 檔案
- **儲存為 PDF**：透過瀏覽器列印功能另存 PDF

## 顯示與閱讀設定

工具提供幾個常用顯示選項：

- **切換暗色模式／亮色模式**：切換整體閱讀主題
- **顯示對話名字**：控制對話前是否顯示角色名稱
- **顯示時間**：控制是否顯示訊息時間
- **混合模式／分頻道模式**：  
  - 混合模式：依時間順序整合顯示所有內容
  - 分頻道模式：依頻道分頁查看內容
- **目錄**：可在編輯模式中將指定段落加入目錄，方便長團錄跳轉閱讀

## 顏色與頻道設定

展開 **「進階顏色與頻道設定」** 後，可以調整：

- 頻道是否顯示
- 頻道標籤名稱
- 頻道背景色
- 頻道邊框色
- 角色對話顏色
- 是否顯示特定角色名稱
- Discord 其他頻道歸類設定

也可以使用：

- **文字顏色統一**：將文字顏色整理成一致樣式
- **重新偵測文字顏色**：重新依匯入內容偵測角色顏色

## 編輯模式功能

切換到 **編輯模式** 後，點選團錄中的段落即可進行操作。

可使用的操作包含：

- 編輯文字內容
- 將段落置中或恢復靠左
- 移動段落位置
- 刪除段落
- 在段落下方新增文字
- 在段落下方新增圖片
- 將段落加入目錄
- 調整手動新增段落的角色與頻道
- 拆開或融合相鄰的區塊段落

這些功能適合用來整理情報、修正文句、插入補充圖片，或調整團錄閱讀順序。

## 支援的文字格式

團錄內容可使用部分簡易 Markdown／自訂格式：

| 寫法 | 效果 |
| --- | --- |
| `**文字**` | 粗體 |
| `//文字//` | 斜體 |
| `__文字__` | 底線 |
| `~~文字~~` | 刪除線 |
| `` `文字` `` | 行內程式碼 |
| ``` ```文字``` ``` | 程式碼區塊 |
| `> 文字` | 引用區塊 |
| `- 項目` | 清單 |
| `#H1-文字-H1#` | 大標題 |
| `#H2-文字-H2#` | 中標題 |
| `#H3-文字-H3#` | 小標題 |
| `#-文字-#` | 較小、較淡的文字 |

## 自動儲存

工具會將目前編輯狀態保存在瀏覽器本機儲存空間中。  
重新整理頁面後，通常可以保留上一次的輸入內容與整理結果。

> 若更換瀏覽器、清除網站資料或使用不同裝置，原本儲存的內容可能不會保留。

## 使用流程建議

1. 填寫劇本名、簡介、KP 與 HO／PL 資訊
2. 匯入 CCFOLIA 或 Discord Log
3. 按下 **「輸出團錄預覽」**
4. 視需要調整顏色、頻道與顯示設定
5. 進入 **編輯模式** 修正文句、移動段落或新增圖片
6. 完成後下載 HTML 或儲存為 PDF

若來源 HTML 結構與預期不同，可能會導致部分內容無法正確讀取。
